# Irbas · sito

Sito di presentazione di Irbas, l'assistente personale per Mac.
HTML, CSS e JavaScript senza librerie: parallax, scene fisse con lo scroll e la sfera di particelle portata da HoloOrb.swift.

## In locale

```
python3 -m http.server 5600
```

Poi apri http://localhost:5600

Pubblicabile così com'è su GitHub Pages.
